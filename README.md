# signlab_docs

User documentation for SignCollect, published at
https://amsterdam-humanities-labs.github.io/signlab_docs/

## Edit
Pages are Markdown in `docs/`. Preview locally:

    pip install mkdocs-material
    mkdocs serve

Every push to `main` rebuilds and publishes the site (`.github/workflows/pages.yml`).

## Rule: this site is public
No server hostnames or IPs other than signcollect.nl, no internal paths, no credentials,
no screenshots showing real participants or personal data.
