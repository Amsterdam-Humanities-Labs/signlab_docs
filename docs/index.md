# SignCollect

SignCollect is the system the UvA SignLab uses to record, process and annotate
Sign Language of the Netherlands (NGT): studio recordings with three to five
cameras, motion capture, gloss management and sentence annotation.

- **New here?** Start with [Getting started](getting-started/index.md).
- **Something not working?** See [Troubleshooting](troubleshooting/index.md).
- **Setting up a server?** See [For administrators](admin/index.md).
- **Setting up a recording studio?** See [Recording studio](studio/index.md).
